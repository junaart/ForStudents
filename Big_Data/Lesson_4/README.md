# Кейс: анализ корреляционной зависимости качественных показателей в жилищно-коммунальном хозяйстве

**Тема:** анализ корреляционной зависимости между качественными (альтернативными, номинальными) показателями с использованием коэффициентов взаимной сопряжённости Пирсона и Чупрова.

**Предметная область:** управление многоквартирными домами (МКД), жилищно-коммунальное хозяйство (ЖКХ).

**Форма выполнения:** четыре практических задания, связанных единым объектом исследования и единым массивом данных. Задания выполняются последовательно: результаты задания 1 используются в задании 2, результат задания 3 используется в задании 4\.

---

## 1\. Паспорт кейса

**Объект исследования:** 400 многоквартирных домов, расположенных в четырёх районах условного муниципального образования и обслуживаемых управляющими организациями трёх форм: товарищества собственников жилья (ТСЖ), управляющие компании (УК), специализированные управляющие организации (СпецУК).

**Источник данных:** файл `data/mkd_gkh.csv` (400 строк, 15 столбцов, кодировка UTF-8). Данные модельные, сформированы с заданной структурой связей (см. `data/generate_data.py`), что позволяет одновременно решать учебные задачи и проверять полученные выводы.

**Цель кейса:** научиться измерять тесноту и характер связи между качественными показателями ЖКХ, выбирать корректный показатель сопряжённости для конкретной таблицы, проверять статистическую значимость связи и переводить результаты в управленческие решения.

**Методический замысел кейса.** Кейс построен так, чтобы обучающийся столкнулся с тремя типичными «ловушками» анализа качественных данных:

1. **Размерность таблицы.** Коэффициент Чупрова зависит от числа групп, поэтому при объединении категорий или сравнении таблиц разной размерности его значения напрямую несопоставимы.  
2. **Смещение коэффициента Пирсона.** Коэффициент Пирсона зависит только от φ² и всегда смещён в сторону завышения меры связи, а его числовые значения «выглядят» сильнее, чем есть на самом деле.  
---

### 2. Шкала интерпретации

Для ${K}_{p}$ (ориентировочная шкала):

| Значение ${K}_{p}$ | Характер связи |
| :---- | :---- |
| $0,2-0,3$ | слабая |
| $0,3-0,4$ | умеренная |
| $0,4-0,5$ | заметная |
| $0,5-0,7$ | сильная |
| $0,7-0,9$ | очень сильная |
| $>0,9$ | практически функциональная |

&nbsp;

Для ${K}_{h}$ шкала «сдвигается вниз» (значения меньше, так как знаменатель больше 1), ориентировочно:

| Значение ${K}_{h}$ | Характер связи |
| :---- | :---- |
| $<0,1$ | практически отсутствует |
| $0,1-0,2$ | слабая |
| $0,2-0,3$ | умеренная |
| $0,3-0,4$ | заметная |
| $0,4-0,6$ | сильная |
| $>0,6$ | очень сильная |

## 4\. Задания

### Задание 1\. Расчёт коэффициентов сопряжённости (таблица 3 × 3\)

**Исходная таблица 1.1.** Тип жилого дома × вид теплоснабжения (n \= 400):

| Тип дома \\ Теплоснабжение | Автономное | Печное | Централизованное | Итого |
| :---- | :---- | :---- | :---- | :---- |
| Блочный | 63 | 4 | 31 | 98 |
| Кирпичный | 20 | 61 | 75 | 156 |
| Панельный | 20 | 2 | 124 | 146 |
| **Итого** | **103** | **67** | **230** | **400** |

&nbsp;

**Что сделать:**

1. Проверить согласованность границ таблицы (итоги по строкам и столбцам), построить расчётные (теоретические) частоты ${f}_{ij}^{*}={k}_{i}{m}_{j}/n$, указать ячейки, в которых наблюдаемая частота равна нулю или отклоняется от расчётной наиболее сильно.  
2. Рассчитать показатель средней квадратической сопряжённости ${\varphi }^{2}$ (с пошаговым расчётом по клеткам и проверкой через встроенную функцию).  
3. Рассчитать коэффициенты взаимной сопряжённости ${K}_{p}$ (Пирсон) и ${K}_{h}$ (Чупров) с точностью до 4 знаков.  
4. Интерпретировать силу связи по шкале п. 2.6 отдельно для ${K}_{p}$ и ${K}_{h}$. Объяснить, почему значения одного и того же расчёта по двум шкалам выглядят по-разному, и какое из них ближе к реальности.  
6. Дать управленческий вывод: какое решение в сфере теплоснабжения следует из таблицы (объём и адресность программы), оценить приоритетность домов каждого типа.  
7. **Проверка устойчивости.** Объедините категории «Печное» и «Автономное» в одну категорию «Нецентрализованное» (таблица 3 × 2\) и пересчитайте ${\varphi }^{2}$, ${K}_{p}$, ${K}_{h}$. Сравните динамику показателей и объясните, какой из них отражает изменение самой связи, а какой — изменение размерности таблицы.
