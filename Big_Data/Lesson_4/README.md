# Кейс: анализ корреляционной зависимости качественных показателей в жилищно-коммунальном хозяйстве

**Тема:** анализ корреляционной зависимости между качественными (альтернативными, номинальными) показателями с использованием коэффициентов взаимной сопряжённости Пирсона и Чупрова.

**Предметная область:** управление многоквартирными домами (МКД), жилищно-коммунальное хозяйство (ЖКХ).

**Форма выполнения:** четыре практических задания, связанных единым объектом исследования и единым массивом данных. Задания выполняются последовательно: результаты задания 1 используются в задании 2, результат задания 3 используется в задании 4\.

---

## 1\. Паспорт кейса

**Объект исследования:** 400 многоквартирных домов, расположенных в четырёх районах условного муниципального образования и обслуживаемых управляющими организациями трёх форм: товарищества собственников жилья (ТСЖ), управляющие компании (УК), специализированные управляющие организации (СпецУК).

**Источник данных:** файл `data/mkd_gkh.csv` (400 строк, 15 столбцов, кодировка UTF-8). Данные модельные, сформированы с заданной структурой связей (см. `data/generate_data.py`), что позволяет одновременно решать учебные задачи и проверять полученные выводы.

**Цель кейса:** научиться измерять тесноту и характер связи между качественными показателями ЖКХ, выбирать корректный показатель сопряжённости для конкретной таблицы, проверять статистическую значимость связи и переводить результаты в управленческие решения.

**Методический замысел кейса.** Кейс построен так, чтобы обучающийся столкнулся с тремя типичными «ловушками» анализа качественных данных:

1. **Размерность таблицы.** Коэффициент Чупрова зависит от числа групп, поэтому при объединении категорий или сравнении таблиц разной размерности его значения напрямую несопоставимы.  
2. **Смещение коэффициента Пирсона.** Коэффициент Пирсона зависит только от φ² и всегда смещён в сторону завышения меры связи, а его числовые значения «выглядят» сильнее, чем есть на самом деле.  
3. **Ложная причинность.** Значимая связь между двумя признаками не означает, что один из них является причиной другого: в кейсе это иллюстрируется цепочкой «этажность → лифт → качество обслуживания → задолженность».

## 2\. Теоретическая справка

### 2.1. Таблица сопряжённости

Для двух качественных признаков, первый из которых принимает значения $A_1,\dots,A_k$, а второй — $B_1,\dots,B_m$, строится таблица сопряжённости:

| Признак | ${A}_{1}$ | ${A}_{2}$ | $\dots$ | ${A}_{k}$ | Итого ${k}_{i}$ |
| :---- | :---- | :---- | :---- | :---- | :---- |
| ${B}_{1}$ | ${f}_{11}$ | ${f}_{12}$ | $\dots$ | ${f}_{1k}$ | ${k}_{1}$ |
| ${B}_{2}$ | ${f}_{21}$ | ${f}_{22}$ | $\dots$ | ${f}_{2k}$ | ${k}_{2}$ |
| $\dots$ | $\dots$ | $\dots$ | $\dots$ | $\dots$ | $\dots$ |
| ${B}_{m}$ | ${f}_{m1}$ | ${f}_{m2}$ | $\dots$ | ${f}_{mk}$ | ${k}_{m}$ |
| **Итого ${m}_{j}$** | ${m}_{1}$ | ${m}_{2}$ | $\dots$ | ${m}_{k}$ | $n$ |

&nbsp;

где ${f}_{ij}$ — число домов, у которых первый признак принял значение ${A}_{j}$, а второй — ${B}_{i}$.

Теоретическая (ожидаемая) частота ячейки при условии независимости признаков:

$${f}_{ij}^{*}=\frac{{k}_{i}\cdot {m}_{j}}{n}$$

### 2.2. Показатель средней квадратической сопряжённости

$${\varphi }^{2}=\left({\sum\limits_{i=1}^{m}\sum\limits_{j=1}^{k}\frac{{f}_{ij}^{2}}{{k}_{i}\cdot {m}_{j}}}\right)-1$$

${\varphi }^{2}$ — мера, «показывающая, насколько распределение частот одной переменной отличается от того, которое было бы при независимости признаков». Свойства: $0\le\varphi^2\le \min(k-1,\,m-1)$; ${\varphi }^{2}=0$ — признаки независимы; ${\varphi }^{2}=1$ — уже заметная связь (при ${\varphi }^{2}=1$ коэффициент Пирсона равен $0,707$).

### 2.3. Коэффициент взаимной сопряжённости Пирсона

$$K_p=\sqrt{\frac{\varphi^{2}}{1+\varphi^{2}}},\qquad 0\le K_p<1$$

Свойства:

* зависит **только** от ${\varphi }^{2}$ и **не зависит** от размерности таблицы (числа групп);  
* ${K}_{p}=0$ — независимость; ${K}_{p}\rightarrow 1$ при ${\varphi }^{2}\rightarrow \infty$ (то есть ${K}_{p}$ никогда не достигает 1 при конечной таблице);  
* **всегда завышает меру связи**: уже при ${\varphi }^{2}=1$ (слабая связь) ${K}_{p}=0,707$, что по любой шкале читается как «сильная связь»;  
* для таблицы $2\times 2$ совпадает по модулю с коэффициентом контингенции Пирсона: ${K}_{p}=|\varphi |$.

### 2.4. Коэффициент взаимной сопряжённости Чупрова

$${K}_{h}=\sqrt{\frac{{\varphi }^{2}}{(k-1)(m-1)}}$$

Свойства:

* учитывает число групп по каждому признаку, поэтому «приводит» разные таблицы к сопоставимому виду;  
* ${K}_{h}=0$ — независимость;  
* максимальное значение (при ${\varphi }_{\max\limits_{}}^{2}=\min\limits_{}(k-1,m-1)$): $K_h^{\max}=\sqrt{\dfrac{\min(k-1,m-1)}{(k-1)(m-1)}}$ — для таблицы 2 × 2 равно 1, для квадратной таблицы $k=m>2$ равно $\dfrac{1}{\sqrt{k-1}}$ (например, 0,707 для 3 × 3), для прямоугольных таблиц — ещё меньше;  
* при изменении числа групп значение ${K}_{h}$ меняется **непропорционально** изменению самой связи, поэтому значения ${K}_{h}$ для таблиц разной размерности напрямую сравнивать нельзя.

**Соотношение коэффициентов.** ${K}_{p}\geq {K}_{h}$ тогда и только тогда, когда $(k-1)(m-1)\geq 1+{\varphi }^{2}$, что для практических таблиц выполняется (максимально возможное ${\varphi }^{2}=\min\limits_{}(k-1,m-1)$).

### 2.5. Связь с критерием ${\chi }^{2}$

$${\chi }^{2}=n\cdot {\varphi }^{2}$$

Критерий ${\chi }^{2}$ Пирсона проверяет гипотезу независимости ${H}_{0}$: «связь между признаками обусловлена случайными факторами». Статистика ${\chi }^{2}$ имеет $\nu =(k-1)(m-1)$ степеней свободы; при $\alpha =0,05$ нулевая гипотеза отвергается, если $\chi^{2}_{\text{набл}}>\chi^{2}_{\text{кр}}(\nu)$ (то есть $p<\alpha$).

Следствие: значимость связи определяется не только её силой (коэффициентом), но и размером выборки, поэтому коэффициенты сопряжённости **всегда следует дополнять** проверкой значимости.

### 2.6. Шкала интерпретации

Для ${K}_{p}$ (ориентировочная шкала):

| Значение ${K}_{p}$ | Характер связи |
| :---- | :---- |
| $0,2-0,3$ | слабая |
| $0,3-0,4$ | умеренная |
| $0,4-0,5$ | заметная |
| $0,5-0,7$ | сильная |
| $0,7-0,9$ | очень сильная |
| $>0,9$ | практически функциональная |

&nbsp;

Для ${K}_{h}$ шкала «сдвигается вниз» (значения меньше, так как знаменатель больше 1), ориентировочно:

| Значение ${K}_{h}$ | Характер связи |
| :---- | :---- |
| $<0,1$ | практически отсутствует |
| $0,1-0,2$ | слабая |
| $0,2-0,3$ | умеренная |
| $0,3-0,4$ | заметная |
| $0,4-0,6$ | сильная |
| $>0,6$ | очень сильная |

&nbsp;

### 2.7. Справочно: коэффициент Крамера $V$

$$V=\sqrt{\frac{\varphi^{2}}{\min(k,m)-1}},\qquad 0\le V\le 1$$

Не входит в обязательную программу расчёта, но полезен как «проверочный» показатель: в отличие от ${K}_{h}$ он сопоставим для таблиц любой размерности, а для квадратных таблиц ${K}_{h}$ и $V$ связаны соотношением $V=\sqrt{k-1}\cdot {K}_{h}$.
